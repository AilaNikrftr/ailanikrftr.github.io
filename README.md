# aila nik · portfolio

A one-page portfolio. The portrait is a live Raft cluster drawn by its own network traffic.

## Files
- `index.html` – all the page text (about, experience, research, projects, contact)
- `style.css` – colors, fonts and layout (the color tokens are at the top in `:root`)
- `raft-portrait.js` – the Raft simulation and portrait drawing (settings like node count and timings are near the top)
- the portrait itself is stored as ~2,500 node positions inside `raft-portrait.js` (no photo is shipped)
